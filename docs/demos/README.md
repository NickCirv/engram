# Showcase media sources

This directory holds historical v2.0.2 presentation material for the Engram showcase. Both `showcase.html` and `hf/index.html` are retained as coordinated scene/player sources, alongside the scene table and captions. Their version strings, timings and savings figures are not current installation guidance or independently verified measurements. The media are separate from the executable demonstration under `demo/` and from benchmark evidence.

| Artifact | Role |
| --- | --- |
| `showcase.html` | Authored scene/player source |
| `scene-table.md` | Historical scene narrative and timing plan |
| `captions.vtt`, `chapters.vtt` | Caption and chapter timing assets |
| `poster.svg` | Poster artwork |
| Generated video files | Delivery artifacts requiring a separate render |

## Editing and review

Update scene copy, timing and captions together. Preserve pause controls, readable contrast, and a reduced-motion presentation. Verify that every quantitative statement in the media has a linked, reproducible measurement before exporting it; older showcase percentages are not validated by this documentation pass.

The previous guide supplied Hyperframes commands and installation steps, but renderer code and its current CLI contract are outside this repository's captured evidence. Use a reviewed renderer version and its own documentation, then record the actual command, codec, dimensions, duration and artifact size. No renderer installation, video generation or playback accessibility test was performed here.

Keep the scene table as a historical production artifact until the corresponding HTML, caption and media assets are revised together. Rewriting its claims alone would leave conflicting published media.
